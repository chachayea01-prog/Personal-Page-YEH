# 葉律言 // 平面畫家展示框架 (Painter Gallery Portfolio)

專為 **平面畫家 葉律言** 打造的個人展示框架。具備寫實動態舞台火焰背景、暗黑搖滾純淨美學、自介頭像相框，以及 YouTube 背景音樂播放與禁音按鈕。

---

## 🎨 核心功能與頁面配置

1. **背景音樂與音量大小控制 (Background BGM & Volume Control)**：
   - 串接指定的 YouTube 音樂（影片 ID：`FhgFtXESdPk`）。
   - 右下角常駐浮動控制面板，提供：
     - **音量滑動條 (0% ~ 100%)**：可隨時拖曳細膩微調音量大小。
     - **喇叭圖示按鈕**：點擊一鍵快速靜音／解除靜音。
     - **聲波跳動動畫 (Equalizer)**：隨聲音播放實時動態跳動。
2. **自我介紹純淨框架 (Intro & Profile Box)**：
   - 創作者姓名：**葉律言 (Yeh, Lu-Yen)**，身分「平面畫家 (PAINTER)」。
   - 自介內容：**普通大學生**。
   - 基本資料：姓名、專業領域、創作媒材（數位繪畫 / 平面創作），無 EMAIL。
3. **個人頭像相框 (Portrait Frame)**：
   - 採用真實美人魚豎琴原畫（`avatar.jpg`），以精確比例與安全倍率（1.22x）展示，**完全不裁切頭頂與魚尾**。
4. **畫作展示框架 (Artwork Frames 01 ～ 06)**：
   - 純淨無假名稱的畫框展示網格，附帶系列篩選標籤與彈窗檢視。
5. **聯絡專區 (Contact Box)**：
   - 連結至官方 Instagram：`@landplains._.95` (https://www.instagram.com/landplains._.95/) 與自訂聯絡表單。
6. **寫實動態舞台火焰背景 (Realistic Stage Fire Canvas)**：
   - 60FPS 自然物理流體熱浪動態與微光餘燼，以純粹的暗黑搖滾舞台氛圍襯托全站。
